Med-IT · Pharmacy ERP

A 2-minute tour of a real pharmacy ERP, in daily use for over five years. Built and maintained by Awad Luckhoo.

In daily use for 5+ years Spring Boot 3 · Java Angular + Ionic MySQL · Flyway JWT security AI-assisted code review

From the counter to compliance, one system.

Fast, safe dispensing

Keyboard-first checkout that sells from each stock batch, with optional discounts and split payments. Controlled drugs require a prescription, so the doctor and patient are attached to the sale, and every sale prints a tax invoice and a receipt.

Batch & expiry control

Deliveries are received per supplier with bonus, cost, price and expiry. Each becomes its own batch, and the dashboard flags low stock and expired batches.

Compliance built in

The psychotropic register fills itself from sales, VAT reports export in one click, and each till is reconciled against expected cash at closing.

Credit customers

Customers buy on account and settle in full or in part, with an agreed discount when needed.

Roles & security

Token-based sign-in. Admins see the full back office; dispensers see only the counter.

Every screen

One Angular and Ionic app on desktop, tablet and phone.

AI-assisted review

A recent AI-assisted code review uncovered and fixed hidden bugs and added new features to a system already in production.
